# Learning Journey Dashboard

A clean, responsive dashboard built with React to track learning progress, metrics, and performance charts. This project was put together for a technical coding challenge.

## 🚀 How to Run the App

### Prerequisites
Make sure you have Node.js installed on your machine:
* **Node.js:** v18 or higher
* **npm:** v9 or higher

### 1. Clone the repository
git clone https://github.com/jgibbons3/dashboard-challenge
cd dashboard-challenge
npm install
npm run dev
Once the server starts, open your browser and head to: http://localhost:5173
